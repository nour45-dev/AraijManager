# سنتر الأرائج التعليمي — Araij Manager Pro v4.0 🚀

منظومة الإدارة والمتابعة والتسجيل وكشوف الحضور والغياب مع المزامنة اللحظية الحية (0ms Live Sync) عبر منصة ريلوي (Railway) وتطبيق الأندرويد.

---

## 🌟 المميزات الرئيسية للمنظومة

1. **المزامنة اللحظية الفورية (Real-time Live Sync)**:
   - دعم كامل لتقنيات WebSockets و REST API لتحديث أي عملية (تسجيل، تعديل، حذف، رصد حضور) عبر جميع الأجهزة في أقل من 50 مللي ثانية.
2. **نظام رصد الحضور شهراً بشهر (Monthly Attendance)**:
   - رصد الحضور لكل شهر على حدة (8 حصص لكل شهر).
   - فتح شهور جديدة بسهولة واحتساب نسب الحضور والغياب والدرجات لكل شهر بشكل مستقل.
3. **كشوف وتقارير PDF رسمية لكل مدرس**:
   - توليد كشوف حضور وغياب منسقة وجاهزة للطباعة لكل مدرس ومادة وشهر مع الحصص (ح1 إلى ح8) والدرجات والرموز والتقييمات وتوقيعات الإدارة.
4. **سجل الرقابة الكامل في Google Sheets (Audit Trail)**:
   - توثيق فوري لكل عملية (إضافة طالب، تعديل، حذف، رصد حضور وغياب) باسم المشرف وتاريخ وتوقيت القاهرة بالثانية.
5. **العمل بدون إنترنت (Offline-First)**:
   - التطبيق يعمل بالكامل حتى عند انقطاع الشبكة، ويقوم بحفظ العمليات ومزامنتها تلقائياً فور عودة الاتصال.
6. **تطبيق أندرويد حقيقي (APK)**:
   - تطبيق مثبت على هواتف المشرفين والإدارة يعمل بتناسق تام مع السيرفر السحابي.

## 🚀 خطوات الرفع على GitHub والنشر على ريلوي (Railway)

### الخطوة 1: الرفع على GitHub
1. افتح حسابك على [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم `AraijManager`.
2. شغّل الأوامر التالية من مجلد المشروع لرفع الملفات:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/AraijManager.git
git push -u origin main
```
*(استبدل `YOUR_USERNAME` باسم المستخدم الخاص بك على GitHub)*.

---

### الخطوة 2: النشر على Railway في خطوة واحدة
1. ادخل على منصة [Railway.com](https://railway.com) وسجّل الدخول بحساب GitHub.
2. اضغط على **+ New Project** ثم اختر **Deploy from GitHub repo**.
3. اختر المستودع `AraijManager`.
4. ستتعرف منصة Railway تلقائياً على ملفات المشروع وتشغل السيرفر فورياً.
5. من إعدادات المشروع (**Settings > Networking**)، اضغط على **Generate Domain** لتحصل على الرابط السحابي الخاص بك (مثال: `https://araij-production.up.railway.app`).

---

### الخطوة 3: تشغيل التطبيق والربط المباشر
- **على المتصفح**: بمجرد فتح الرابط في أي متصفح، سيعمل النظام والمزامنة اللحظية فوراً.
- **على تطبيق الأندرويد**: افتح نافذة **إعدادات الربط السحابي** وضع رابط Railway ليعمل التطبيق مباشرة وبشكل دائم.
